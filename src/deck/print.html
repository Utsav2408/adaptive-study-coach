Solution

Most adaptive tools adjust difficulty by right/wrong. We go deeper — every wrong answer is classified into one of five error types.

Conceptual

Misunderstood the core idea

Procedural

Correct concept, wrong steps

Misapplied

Used right method on wrong problem

Prerequisite

Missing foundational knowledge

Misread

Understood problem, misread detail

Actionable

Each type → different fix

"You understand quadratics conceptually, but keep making procedural errors" → targeted practice

How It Works

  1. Onboard
    Set study focus and proficiency level
  2. Diagnostic quiz
    AI-generated questions tailored to your subject
  3. Error classification
    Every wrong answer tagged with error type + explanation
  4. Targeted practice
    New questions generated for your exact gaps
  5. Track progress
    Dashboard shows mastery, gaps, and trends
